# Component source

These locally owned primitives are adapted from the StyleX registry in
[`shadcn-labs/shadcn-cssinjs`](https://github.com/shadcn-labs/shadcn-cssinjs/tree/5f0337ee4606f5d6c8f3cb2cb95924c8a70e9a5f/apps/www/registry/bases/stylex/ui)
at commit `5f0337ee4606f5d6c8f3cb2cb95924c8a70e9a5f`.

ProductCompare's semantic tokens, 44px interaction targets, and warm mineral
visual language replace the registry defaults. Base UI remains the only
behavioral primitive dependency used by this directory.
