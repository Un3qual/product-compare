# Frontend Inferred Type Simplification

## Snapshot

- Status: complete
- Priority: P1
- Requested: 2026-08-12 after Product Discovery And Evaluation.
- Owner: current detached worktree.

## Target Outcome

The whole frontend prefers inference and generated Relay contracts over local
annotations, duplicated response schemas, and generic route helper files while
retaining explicit types at public component, URL, storage, transport, custom
scalar, and exhaustive-union boundaries.

## Owned Paths

- `assets/src/**`, generated Relay artifacts, and focused frontend tests.
- This lane document and the active dispatcher row.

## Internal Slices

1. Inventory redundant declarations and annotations.
2. Replace successful GraphQL response schemas with generated Relay types.
3. Remove or relocate generic root route helpers to their real owners.
4. Infer local values and result types across remaining route/UI modules.
5. Run focused, structural, complete frontend, and browser gates.

## Guardrails

- Do not erase useful discriminated unions, exported component contracts,
  exhaustive checks, external-library adaptation, or validation at untyped
  browser/network/URL/storage/custom-scalar boundaries.
- Do not use assertions merely to reduce annotation counts.
- A moved helper must gain a concrete owner; do not rename slop into another
  generic utility file.

## Completion Evidence

- Relay scalar mappings now generate the existing date, datetime, and decimal
  fields as strings instead of `any`; route helpers derive their inputs from
  generated query, fragment, mutation, and input types instead of recreating
  successful GraphQL payload schemas.
- Nullable and optional states follow the generated or library contract. The
  shared Relay completion-error type is derived from `MutationConfig`; helpers
  no longer widen generated fields with hand-authored `| undefined` branches.
- Local JSX return annotations, one-off result interfaces, and redundant local
  constant annotations were removed where TypeScript can preserve the same
  contract through inference, `ReturnType`, `Pick`, or `satisfies`.
- Generic files were removed from the route root. Relay loaders, mutations,
  pagination, and scalars now live under `relay/`; formatting, form, head,
  navigation, and immutable-state owners live under `frontend/`; offer
  snapshots live with the offer capability. Barrel exports cover the grouped
  scalar, formatting, and head APIs.
- The catalog no longer renders product slugs as metadata. Root route files are
  now limited to actual root route components.
- Relay artifacts were regenerated by Relay itself after detecting that an
  earlier formatter pass had made compiler-owned output stale.
